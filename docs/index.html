Agents & Tasks: who needs you, what's running, what just finished.

Built around what you wait on

Not another everything-app. Every feature earns its place by helping someone who has work running in the background or is building something right now.

✋

Agents that need you

Claude Code and Codex report running, needs you, done or error per project. The notch bounces and chimes; press J to jump to the right terminal.

⏱

islet run anything

islet run npm test shows the task live, chimes at the end, passes the exit code through. Stop or re-run it from the notch.

🪄

Context-aware

The App tab turns into a git panel in VS Code, a sharing tool in Chrome, a task manager in Terminal. It only appears when it can help.

🧭

Dev glance

Listening ports with open and kill. Your open GitHub PRs with CI status and review state.

📊

Claude usage

Tokens in the current 5-hour window and when it resets, with an optional budget bar.

☕

Stays awake for you

Keeps the display awake while agents or tasks run, then lets it sleep.

And yes, the basics too: now playing, next meeting with one-click Join, timer and Pomodoro, File Shelf with AirDrop, battery and Bluetooth alerts, mic and camera dots with All Mute.

It changes with the app you're in

Open the notch over a different app and you get different tools.

VS Code / CursorBranch and changes, an AI-written commit message (never commits without your click), stash dashboard, undo commit, a git guide filled in with your repo's names, run tests, this project's dev servers.
Chrome / Brave / Safarilocalhost → phone QR, Share publicly with a live link, window size presets, clean and Markdown links, GitHub PR and issue helpers.
TerminalLive tasks with Stop, recent tasks to copy or re-run, your last 15 commands with secret-looking lines hidden.
FinderCopy absolute or git-relative paths, open Terminal here, images → PDF.
Preview & FigmaDrag PDFs onto the notch to merge them. Pick colours from the screen in Figma.
Any appAdd your own buttons that run shell commands as tracked tasks.

One command for long tasks

Output stays in your terminal. The notch shows elapsed time, then ✓ or ✗ with a chime. Any tool can report in as an agent.

# watch anything
islet run npm test
islet run swift build -c release

# report from any agent or script
islet agent waiting --name "My Agent" \
  --project api --message "Approve deploy?"

Install in a minute

Islet isn't notarized yet, so macOS asks you to confirm it once.

Download Islet.dmg

Requires a Mac with Apple silicon (M1 or later) and macOS 14 Sonoma or later. Build from source.

  1. Open the DMG and drag Islet to Applications.
  2. Open Islet. If macOS blocks it: System Settings → Privacy & Security → Open Anyway.
  3. Follow setup: Accessibility for the shortcut, connect Claude Code, install the islet command, and optionally sign in to GitHub.
  4. Hover the notch. That's it.

Your notch, finally working for you.

Free, open source and private. Runs entirely on your Mac.
